# 컬렉션 안에서 게임 설정 펼치기

## 동작

- 첫 화면·홈 복귀·컬렉션 복귀·새로고침은 모든 카드를 접힌 상태로 표시합니다.
- 오목·리버시 카드 전체를 클릭하면 같은 컬렉션 안에 썸네일, 로컬/AI 설정, 테이블에 앉기, 저장한 대국 이어하기가 나타납니다. 선택만으로 페이지 이동·3D 장면·AI 계산을 시작하지 않습니다.
- 한 게임만 펼쳐집니다. 선택한 카드를 다시 누르면 접힙니다. 필터, 키보드 Enter/Space, 터치와 포커스 유지도 지원합니다.
- 리버시의 대국 설정은 컬렉션의 리버시 카드를 펼칩니다. 저장한 대국을 이어가면 기존 난이도·색상을 유지하며 새 대국에 변경된 설정을 적용합니다.
- 오목·리버시 설정은 독립적으로 유지하고, 저장 쓰기가 차단돼도 카드 사이를 전환하는 동안 메모리에 보존합니다. 미구현 게임은 개발 예정으로 비활성화합니다.

## 검증

- Chromium PC·Pixel 7 에뮬레이션에서 서로 다른 **16개 시나리오의 최신 결과 통과**.
- 신규 컬렉션 3개 시나리오 × 2개 플랫폼: 초기 접힘·현재 페이지 유지·썸네일·설정·필터·키보드·터치·저장 차단.
- 기존 통합 5개 시나리오 × 2개 플랫폼: 실제 마우스·터치 착수, 저장·재개·카메라·재시작, 난이도/색상·다음 대국 정책, 두 게임 간 Worker 취소와 프레임 진행.
- 최초 통합 실행은 8/10 통과. 모바일 난이도 설정 시나리오 두 개에서 첫 화면 준비까지 포함한 응답 제한을 초과했습니다. Worker 시작 대기와 실제 AI 응답 검사를 분리한 뒤 신규 컬렉션 6개 + 해당 설정 시나리오 4개를 다시 실행해 **10/10 통과**했습니다. 단일 실행에서 전체 16개를 통과했다는 의미는 아닙니다.
- `npm run build:html` 성공. 타입 검사, 프로덕션 빌드, 두 AI Worker를 내장한 `dist/world-table-games.html` 생성 포함.
- `git diff --check` 통과. 규칙·AI 탐색 알고리즘과 의존성은 변경하지 않았습니다. 전체 44개 브라우저 테스트나 AI 대전 리그를 다시 실행하지 않았습니다.
- 실제 모바일 기기의 검증, 원격 푸시 및 환경 게시를 수행하지 않았습니다.
