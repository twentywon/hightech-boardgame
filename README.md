# World Table Games

설치 없이 브라우저에서 즐기는 3D 테이블 게임. 첫 게임은 15×15 자유룰 오목입니다. 독자적인 UI, 프로시저럴 나무 텍스처, Three.js 메시와 Web Audio 합성음을 사용합니다. 서버·계정·외부 에셋은 필요하지 않습니다.

## 실행

Node.js 24 LTS 권장. 검증 환경: Node 24.22.1, npm 11.9.0.

```sh
npm install
npm run dev
npm run build
npm run preview
npm test
```

`package-lock.json`을 커밋했습니다. 재현 가능한 설치에는 `npm ci`를 사용하세요. 클라우드에서 기본 npm 캐시 쓰기 권한이 없다면 `npm ci --cache /tmp/wtg-npm`을 사용합니다.

## 브라우저 테스트

```sh
npx playwright install chromium
npm run test:e2e
# 이미 설치된 Linux Chromium 사용:
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

테스트는 개발 서버를 자동 실행합니다. 데스크톱과 Pixel 7 에뮬레이션에서 WebGL을 실행하고 마우스/터치 착수, 새로고침 후 재개, 재시작, AI 응답, 설정과 콘솔 오류를 검증합니다. `test-results/`에 메뉴와 게임 스크린샷이 생성됩니다. 클라우드 테스트는 SwiftShader 소프트웨어 렌더링을 사용합니다. 실제 iOS Safari, Android 기기, Firefox의 성능과 오디오 청감은 별도 검증 대상입니다.

## 플레이

- 컬렉션에서 로컬 2인 또는 컴퓨터 대전을 선택합니다. 컴퓨터전에서는 사람이 흑, AI가 백입니다.
- PC: 교차점에 마우스를 올려 미리보고 클릭합니다.
- 모바일: 터치·드래그로 후보를 고른 후 착수 확정 버튼을 누릅니다.
- 키보드: 게임판에 초점을 둔 뒤 방향키로 후보 이동, Enter로 착수합니다.
- 흑 선공, 5개 이상 연결 시 승리, 금수 없음. 승리한 연속 좌표 전체를 강조합니다.
- 시점 전환은 사선/수직, 효과음과 렌더링 해상도는 설정에서 변경합니다.
- 매 착수마다 기기에 저장됩니다. 새로고침 후 메뉴의 이어하기로 재개합니다. 손상된 저장은 무시합니다. 브라우저 저장을 차단한 경우 게임은 계속되지만 저장 실패가 표시됩니다.
- 게임 방법에서 규칙과 초보자를 위한 시작 안내를 제공합니다.

## 구조

- `src/core/`: 게임 카탈로그, 세션·설정 저장과 복구
- `src/games/gomoku/`: DOM/Three.js에 독립적인 규칙, 상태 타입, 좌표 변환, 초급 AI
- `src/engine/`: 씬, Raycaster 입력, 카메라, 애니메이션, 메시 생성·해제, 합성 효과음
- `src/ui/`: 컬렉션, 플레이 UI, 설정·규칙·결과 대화상자
- `tests/`: Vitest 규칙 테스트 및 Playwright 브라우저 테스트

AI는 즉시 승리 → 즉시 패배 방어 → 주변 후보의 연속 돌·열린 끝 평가 순으로 선택합니다. 선택한 수는 반드시 규칙 엔진에서 검증합니다. 메시 생성은 `BoardView.makeStone`에 모여 있어 추후 모델 에셋으로 교체할 수 있습니다. 온라인 서버나 불필요한 범용 게임 엔진은 포함하지 않습니다.

## 정적 배포

기본 `base`는 `./`입니다. 특정 하위 경로가 필요하면:

```sh
BASE_PATH=/hightech-boardgame/ npm run build
```

`dist/`를 정적 호스팅에 올립니다. 파일을 직접 여는 대신 HTTP 서버를 사용하세요. GitHub Pages 자동 배포나 저장소 공개 설정은 활성화하지 않았습니다.

## 현재 범위

오목만 플레이 가능합니다. 오셀로·체스·블랙잭·요트 다이스는 개발 예정 카드입니다. 중급/상급 AI, 온라인 대전, 계정, 다단계 체험형 튜토리얼은 이후 작업입니다. Three.js 포함 번들 크기 경고는 기능 오류가 아니며 향후 지연 로딩 최적화 대상입니다.
